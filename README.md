# Komentář k vyhlášce Českého úřadu zeměměřického a katastrálního č. 31/1995 Sb., kterou se provádí zákon č. 200/1994 Sb., o zeměměřictví a o změně a doplnění některých zákonů souvisejících s jeho zavedením

Otevřený komentář k vyhlášce k provedení zákona o zeměměřictví — § po §: doslovné znění, výklad, zmocnění a jeho meze, kazuistika, protiargumenty a praktický závěr; bodová pole, státní mapová díla a databáze, geografické názvosloví, výsledky zeměměřických činností a jejich ověřování, autorizační razítko a technická příloha.

Konsolidované znění: dokument e-Sbírky `SB-1995-00031_2025-08-01`.
